## 💡 Concepts Learned
1. **4 Layers of AI Assistant:** Input → Brain → Action → Output
2. **LLM (Large Language Model):** Smart text predictor trained on massive data; we're using Llama 3.3 70B via Groq
3. **API (Application Programming Interface):** Like a waiter - takes requests from my code to external services and brings back responses
4. **API Keys:** Personal identifier for using services - handles authentication, usage tracking, billing, and security
5. **Cloud vs Local:** Cloud = runs on others' powerful servers (current trial); Local = runs on my own PC (future phase)
6. **pip install:** Python's package manager - downloads libraries (like groq) from PyPI
